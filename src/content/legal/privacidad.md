# Política de privacidad

Última actualización: 1 de julio de 2026.

## Quiénes somos

Soluciones Fabrick ofrece productos, servicios, cotizaciones, asesoría y coordinación de proyectos relacionados con hogar, construcción, remodelación e instalación.

## Qué datos podemos solicitar

Podemos recopilar datos que el usuario entrega voluntariamente, como nombre, correo electrónico, teléfono, comuna, dirección referencial, mensaje, tipo de proyecto, productos de interés, fotografías enviadas y antecedentes necesarios para responder una solicitud.

## Para qué usamos los datos

Usamos los datos para responder consultas, enviar cotizaciones, coordinar visitas, entregar soporte, gestionar pedidos, registrar oportunidades en CRM, mejorar la atención, cumplir obligaciones comerciales y prevenir abusos o errores operativos.

## Base de tratamiento y consentimiento

Al enviar un formulario, aceptar cookies no esenciales o contactarnos por un canal disponible, el usuario autoriza el uso de sus datos para la finalidad informada.

El usuario puede rechazar cookies no esenciales desde el aviso del sitio. Las cookies necesarias para funcionamiento básico pueden mantenerse activas.

## CRM, correo y herramientas externas

La información enviada por formularios puede guardarse en la base de datos del sitio, en el CRM interno y enviarse por correo al administrador para dar seguimiento rápido.

También podemos usar proveedores tecnológicos para correo, analítica, hosting, base de datos, pagos, mensajería o seguridad operativa. Estos proveedores solo deben usar la información para prestar el servicio correspondiente.

## Cookies y analítica

Podemos usar cookies esenciales para recordar preferencias, carrito, sesión o seguridad. También podemos usar cookies de analítica o medición si el usuario las acepta.

## Derechos del usuario

El usuario puede solicitar información sobre sus datos, pedir corrección, actualización, eliminación cuando corresponda, o retirar su consentimiento para comunicaciones no esenciales.

Para ejercer estos derechos, puede escribir al correo o canal de contacto informado por Soluciones Fabrick.

## Conservación de datos

Conservamos los datos por el tiempo necesario para responder solicitudes, mantener historial comercial, cumplir obligaciones, proteger la seguridad del sitio o resolver reclamos.

## Seguridad

Aplicamos medidas razonables para proteger la información. Aun así, ningún sistema digital es completamente infalible, por lo que el usuario debe evitar enviar datos sensibles innecesarios por formularios públicos.

## Menores de edad

El sitio no está dirigido a menores de edad. Si se detecta información enviada por un menor sin autorización, podrá ser eliminada.

## Cambios en esta política

Esta política puede actualizarse para reflejar cambios operativos, tecnológicos o legales.

## Contacto

Para consultas sobre privacidad, datos personales o eliminación de información, el usuario puede escribir al correo de contacto de Soluciones Fabrick o al canal que aparezca en el sitio.

## Nota importante

Esta política es una base informativa adaptada al funcionamiento del sitio. Para cumplimiento definitivo o tratamiento de datos de mayor escala, se recomienda revisión legal profesional.
